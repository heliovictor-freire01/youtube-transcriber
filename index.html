✨ Insights com IA — Claude (Anthropic)

1
Crie sua conta na Anthropic

Acesse console.anthropic.com e crie uma conta.

2
Gere uma API Key

Em Settings → API Keys, clique em "Create Key" e copie o valor.

3
Adicione no Vercel

Settings → Environment Variables → ANTHROPIC_API_KEY

🎙 Transcrição por áudio — AssemblyAI

Ativa como fallback automático para vídeos sem legendas. Plano gratuito com 5h/mês.

1
Crie sua conta no AssemblyAI

Acesse assemblyai.com → plano gratuito disponível.

2
Copie sua API Key

No dashboard, sua chave fica em Account → API Key.

3
Adicione no Vercel

Settings → Environment Variables → ASSEMBLYAI_API_KEY → Redeploy.
